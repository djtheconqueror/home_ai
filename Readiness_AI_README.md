# Readiness AI v1

Readiness AI is an early-stage machine learning project focused on predicting human performance readiness using synthetic health, fatigue, and workload signals.

## Overview

The model estimates whether an individual is in a READY, CAUTION, or RECOVER state based on simulated readiness indicators.

## Features

The current model uses:

- sleep_hours
- stress_score
- hydration_score
- soreness_score
- training_load
- resting_hr
- cognitive_fatigue

## Current Capabilities

- Synthetic readiness dataset generation
- Random Forest classification
- Multi-class prediction: READY / CAUTION / RECOVER
- Scenario-based testing
- Executive readiness report
- Feature importance visualization
- Model artifact export
